# Spendwise 💸

A simple website to add your daily spending and see the total.

🔗 **Live demo:** https://jenishpatel2508.github.io/spendwise/

## Features

- Add an amount and a category (food, travel, etc.)
- See the total spending instantly
- See a list of all spendings
- Delete any spending
- Data is saved in the browser, so it stays after refresh
- Works on mobile and desktop

## Built with

- HTML
- CSS
- JavaScript (with localStorage)

## What I learned

- How HTML, CSS and JavaScript work together
- How to handle button clicks and update the page with JavaScript
- How to save data with localStorage
- How to publish a project with GitHub Pages
